# Compute Module Hub Hardware Design

This directory contains the ECAD files (schematics, PCB layout, and BOM) for the Compute Module Hub carrier board.

## Specifications
- SoC reference platform supporting low-power ARM architecture.
- Integrated Wi-Fi 6E/7 radio interface for direct 6 GHz mesh networking.
- Single USB-C interface for debugging/provisioning.
- No display or user interface components (headless).
